Project A: AI call-evaluation platformMulti-tenant SaaS · my role: sole AI engineer ·

Problem
Score customer-service calls consistently on tone, resolution quality and compliance, while keeping sensitive data protected.
What I built
  • The AWS architecture, solo: Lambda, Fargate, ECS, EC2 and SQS.
  • A LangChain / LangGraph agent pipeline (Claude and OpenAI, swappable to Groq or Bedrock) with RAG on pgvector and tool calling.
  • A calibration module that compares AI scores with human QA reviewers.
  • AssemblyAI transcription and diarization, with LLM post-processing for speaker attribution on mono audio.
  • Guardrails and LangSmith tracing.
  • HIPAA-aligned controls: masking, encryption, audit logging, access control and retention.

Project B: Interpreter dispatch and evaluation platformReal-time, event-driven · my role: backend engineer ·

Problem
Route each incoming request to the best-fit interpreter quickly, then evaluate interpreter quality.
What I built
  • A dispatch engine on Redis pub/sub and cache that scores interpreters on utilization, weighted average wait time and language availability.
  • A re-architecture on AWS (EventBridge, ElastiCache, SQS).
  • RBAC from scratch in FastAPI: 20 default roles plus custom roles, with JWT, OAuth and TOTP MFA.
  • Now architecting a multimodal (NLP + video) evaluation engine with RAG, tool calling and guardrails.
